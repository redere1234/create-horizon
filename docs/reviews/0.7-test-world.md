# CreateFactory07 review route

This route describes the new private `CreateFactory07` world prepared for the
0.7 development checkpoint. It does not overwrite `CreateFactory06`, older
review worlds, Prism instances, or a player's current save. A successful authoring
receipt and a separate independent audit of a clone are required before handoff.
The exact accepted binary and evidence must be recorded by the final build runner.
Both are complete for this checkpoint: see [REPORT_07.md](0.7-report.md). The audit
was resumed after a source-proven collection-face fixture correction; the
initial failed attempt remains preserved. The delivered source save was unchanged.

The floor is at Y127; the player's walking level is Y128. The bounded platform
covers X0–55, Z0–39. Glass rails protect the edges. All original model, texture,
locale and audio bytes remain in the player's private JAR/cache.

Goggles are equipped. The first nine inventory slots contain a Wrench, Encased
Chain Drive, Creative Motor, Shaft, Cogwheel, Mechanical Press, Depot, Basin and
Encased Fan. At most 36 distinct stacks are carried. The two catalog barrels at
`2 128 2` and `4 128 2` contain all 48 public catalog IDs, split into 24 occupied
slots each. No overflow is spawned. A separate material barrel at `6 128 2` and
Crafting Table at `8 128 2` support manual rebuilding and survival crafts.

The six chain rigs start at 32 RPM. Processing motors are saved at exactly zero.
These zeros come from ordinary motor placement with its NBT loaded before first
initialization. They are not GUI settings: the original value-settings UI clamps
zero to one. To stop a running rig during this review, disconnect its input shaft
or remove its motor; do not assume that choosing zero in the menu stops it.

For each chain rig, check the start/middle/end shapes and exposed shaft direction.
Use the Wrench on the middle segment and observe the source state update. Remove
the middle segment: the disconnected endpoint must stop. Reconnect it using a
spare Chain Drive with the appropriate shaft orientation. Finally use the actual
motor UI to reverse to −32 RPM, then return to 32. Observe the rotation of every
segment and the output shaft. Numeric speed alone does not establish visual parity.

When wrenching a Creative Motor, aim outside its highlighted value-setting box.
A click inside that box is handled by the original-style settings interaction,
including when a Wrench is held. Do not interpret that centered click as a failed
rotation. Holding the ordinary use button over the setting opens its value board.

Keep both lava enclosures intact. Lava is at `32 129 32` and `32 129 36`, with
glass below/above/beside it, an Encased Fan to the west and Iron Bars to the east.
The bars preserve the intended airflow path; opening the glass can spill lava.
Do not stand in the blasting stream. The two inputs deliberately test only
ordinary stacks and the canonical full-fire flag. Partial resistance selectors,
custom damage tags, unrelated damage sources and malformed components have
separate bounded contracts and are not demonstrated by these lanes.

## Authoring and evidence

The public builder defaults to a read-only plan:

```sh
python3 tools/review_world_07.py --plan
```

Only an explicitly requested build starts an isolated NativeCheckSession:

```sh
python3 tools/review_world_07.py --build --graphics \
  --game /path/to/accepted/horizon-client \
  --resources /path/to/prepared/26.3 \
  --ctl /path/to/horizon-ctl \
  --create-jar /path/to/create-1.21.1-6.0.10.jar \
  --build-receipt /path/to/successful-build-result.json
```

The receipt must identify the exact executable path and SHA256. The CLI creates
a fresh private home; the callback requires its matching marker. It creates a tiled, loaded private
platform, checks the bare Chain Drive's `axis_along_first=true` default, all six
powered canonical chain rigs, stopped processing stocks, catalog capacity and
lava containment. With graphics enabled it records six rig frames and one
platform overview. The game is saved and closed normally. These are authoring
checks; the images still require review, and a separate auditor must test the
actual prepared scene on a disposable clone before delivery.

Report the station, action, expected result, actual result and screenshot path.
Preserve failed attempts instead of replenishing or repairing a failed mechanism
inside an acceptance run. Full Create support, arbitrary schematics, multiplayer,
complete effects/audio parity and cross-version world exchange are not implied.
