# Contraption review world

This world is a separate developer instance. The starter next to it launches
the matching native build. It uses the original Create models when the private
6.0.10 JAR is present. The same blocks and recipes work with the built-in models.

The fields and tree can be tested once without resetting their blocks. Random
ticks are disabled to keep crop ages and saplings steady in this world. Take a
world backup or copy before the destructive stations if you want to replay
them from the beginning.

Try saving and reopening the world while a rotor is active. For a separate
recovery test, place a block where a rotor would land and remove the bearing.
Clear the obstruction and check that the payload returns once. This adapter
requires the whole swept volume to fit within one loaded chunk column. Moving
chest menus, multiple inventories, chassis on other drivers, glue previews,
passenger edge cases, exact presentation and Sable physics remain open.

To check cutting across a restart, use the Moving Saw station. Save and exit
while the saw is stopped against the trunk. Reopen the world and watch the
same cut finish, then check that the bearing resumes.
