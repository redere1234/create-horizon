# Create Factory 0.8

This creative world has two adjustable chain drives and a copper casing bench.
The stations use the Create 6.0.10 behavior tested on Minecraft 1.21.1 and
Horizon 26.3.

| Station | What to try | Expected |
| --- | --- | --- |
| Left chain | Flip the lever next to the Adjustable Chain Gearshift. | The Creative Motor remains at 32 RPM. The plain drive and its shaft change between 32 and 64 RPM. |
| Right chain | Flip the other lever. The motor drives the plain end here. | The adjustable end changes between 32 and 16 RPM. The plain end remains at 32 RPM. |
| Analog input | Replace a lever with a dust line on the floor and supply an intermediate signal. | With signal 7, the ratio is 1.5. The left rig's output is 48 RPM. Removing the signal returns it to 32. |
| Copper casing | Apply a copper ingot to the stripped oak, stripped bamboo or stripped crimson hyphae at the bench. | Each becomes a Copper Casing. In Survival one ingot is spent. Applying an ingot to an unstripped oak log leaves it as it was. |

Wear Engineer's Goggles and look at either Speedometer to read the RPM. The Adjustable Chain Gearshift is
available in Creative. Its original recipe needs an Electron Tube, which is
still part of the planned survival progression.

The reference checks compare all 16 settled signal strengths in each direction
and a native process restart. The copper casing checks compare results and
remaining copper after a real right click. The tests cover these scenes. The
Java order of neighbor notifications, frame-by-frame animation, casing
connected textures and the Create advancement are still pending.
