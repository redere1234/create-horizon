# 0.7 checkpoint: chains and source events

Version **0.7.0-alpha.1**, branch `stage/parity-06`, verified on 2026-11-05.
This is a tested developer checkpoint with a separate prepared review world.
The owner's installed Launcher instance remains **0.6.0-alpha.2**. No GitHub
release or native-registry proposal has been submitted for this checkpoint.

## What changed

- **Encased Chain Drive**: original 24 states, source placement/neighbor shape
  updates, 1:1 transmission, perpendicular shaft connections, Wrench behavior,
  two crafting recipes and canonical `create:encased_shaft` data. The actual
  original default `axis_along_first=true` was checked in Java, correcting the
  first oracle's authored assumption. Adjustable Chain Gearshift remains pending.
- **Generator events**: initialize and publish rotation through actual source
  events, keeping GUI, crank, flow and wrench actions distinct from raw NBT reads.
  Press/Basin startup now respects actual ticker order, without a timer offset.
  Publication is bounded per solved component/tick, with explicit invalidation
  and cleanup of removed/replaced block-entity lifetimes.
- **Placement connections**: use explicit machine shaft contracts. Basin, Mixer,
  burner and belt states no longer gain an incorrect shaft merely from mod
  ownership. Typed native tests cover 3,018 state faces.
- **Fan stack components**: read effective fire resistance, including explicit
  removal of defaults. Map the target full-fire tag to the original unit flag,
  preserve recipe priority and retain unsupported selectors conservatively.
- **Tooling and documentation**: public documentation is English; original game
  localizations are preserved. Exercised machine fixtures now use explicit motor
  placement/initialization instead of treating `/data` as a settings callback.

The catalog contains **28 block items + 20 standalone items = 48 entries**,
**139 recipes** and **41 tags**. The private JAR importer uses schema 12 and
prepares 426 resource files, retaining all 61 original locales. Original assets
and JARs are not published in this repository.

## Review world

**CreateFactory07** contains six chain orientations, 48 catalog entries in two
barrels, survival-crafting stock, a stopped eight-ingot Depot/Press, a stopped
eight-snowball Basin/Press, and two contained fan-blasting lanes comparing
ordinary and full-fire-resistant Diamonds. Goggles and tools are ready.
The route and coordinates are in [TESTING_07.md](0.7-test-world.md).

The authored source remained closed and byte-identical while an independent
agent exercised a disposable clone. **23 recorded groups**, **16 personally
inspected screenshots** and **two complete process-restart comparisons** passed.
Actual survival crafting consumed delivered ingredients; machine stocks were
not replenished. Eight ingots produced eight sheets, eight snowballs produced
two blocks, normal Diamonds were destroyed and protected Diamonds persisted.
The empty Depot was visually checked after collection.

Acceptance is explicitly **composed/resumed**: the first audit tried collecting
from SOUTH, which original `SharedDepotBlockMethods.onUse` correctly rejects.
The same closed clone resumed with a real empty-hand UP click, with all eight
sheets conserved. The original failed aggregate, transcript, logs and images
remain unchanged. No production fix or machine replenishment was used to pass.
No full clean rerun after this fixture correction is claimed.

The private evidence is intentionally not distributed with original resources.
Local receipts are `review07-source-9f4_w03z/result.json` and
`review07-audit-13osp09o/resume-result.json` under `.local/`; the final audit
receipt SHA256 is `281f2234704d1583c69f230b21fc098ba32618ef2e58d80db73417e1e587f4e2`.
Public reproduction tools are `tools/review_world_07.py` (read-only plan by
default) and `tools/review_world_07_audit.py` (fresh disposable clone).

The prepared private home includes `Launch-Create-07.command`, which opens this
world on the exact accepted binary with its resources and native metadata.
It is a developer launch, not an update of the installed official Launcher.
The generic macOS metadata fix remains [PR #9529](https://github.com/horizon-rust/horizon/pull/9529).
Older owner worlds and Prism instances are preserved.

## Remaining work

This increment does not establish whole-mod or complete presentation parity.
Full RotationPropagator ownership/rebuilding, flicker/breakage, instantaneous
detach semantics and authentic cold-loaded Java networks remain open. General
damage-selector/component migration, multiplayer, broad shared schematics,
all UI/particles/audio and all older effect/map fixtures need further work.

Next review should focus on chain appearance/rotation and real settings/Wrench
interactions, then the supported transport/processing gaps. Continue adding
bounded original features with the same Java/native verification. Moving
contraptions remain later scope. The complete checklist is in
[ROADMAP.md](../roadmap.md); the rough overall coverage estimate remains **8–10%**,
not a measured feature percentage or a claim of 25% completion.
